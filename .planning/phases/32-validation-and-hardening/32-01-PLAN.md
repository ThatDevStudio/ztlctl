Add the following new test functions to `tests/plugin/test_plugin_structure.py`, keeping existing tests unchanged:

1. **test_plugin_json_version_semver** — Verify `plugin.json` version matches `^\d+\.\d+\.\d+$` and is >= "1.0.0"

2. **test_plugin_changelog_exists** — Verify `plugin/CHANGELOG.md` exists and contains the current version from `plugin.json`

3. **test_skill_descriptions_no_overlap** — Load all `SKILL.md` files from `plugin/skills/*/SKILL.md`, extract the `description:` field (multiline YAML), and verify no two descriptions share more than 50% of their significant words (exclude stop words like "the", "a", "when", "use", "for", "to", "or", "and", "in", "is", "of", "with", "that"). This catches descriptions that are too similar. Use a simple Jaccard coefficient on word sets with threshold 0.5.

4. **test_skill_line_counts_under_limit** — All `SKILL.md` files must be under 500 lines (Pitfall #7 prevention)

5. **test_side_effect_skills_have_disable_model_invocation** — Skills that contain write-operation MCP tool references (`create_note`, `create_reference`, `create_task`, `session_start`, `session_close`, `confirm_contradiction`, `reweave`) in their SKILL.md body MUST have `disable-model-invocation: true` in frontmatter. Parse each SKILL.md, check body for these tool names, and if any are found, verify the frontmatter has the flag.

6. **test_agent_frontmatter_no_unsupported_fields** — Parse each `plugin/agents/*.md` frontmatter (YAML between `---` markers). Verify no agent uses unsupported fields: `hooks`, `mcpServers`, `permissionMode`. Only allowed fields: `name`, `description`, `model`, `effort`, `maxTurns`, `tools`, `disallowedTools`, `skills`, `memory`, `background`, `isolation`.

7. **test_mcp_json_no_path_traversals** — Verify `.mcp.json` does not contain `../` path traversals

8. **test_readme_component_counts_accurate** — Parse `plugin/README.md`, find the component count table, verify Skills count matches actual `plugin/skills/*/` directory count, Commands count matches actual `plugin/commands/*.md` file count, Agents count matches actual `plugin/agents/*.md` file count

9. **test_hook_exit_codes_documented** — Read `plugin/hooks/scripts/vault-gate.sh`, verify it contains both `exit 0` and `exit 2` patterns (correct exit code usage per Pitfall #9)

10. **test_all_skills_have_name_field** — Every `SKILL.md` must have a `name:` field in frontmatter

Use `pytest.param` and `@pytest.mark.parametrize` where appropriate for per-skill tests. Import `yaml` for frontmatter parsing — use a simple split-on-`---` approach to extract frontmatter (do not add a pyyaml dependency; use the existing approach of manual parsing or `re` patterns). Actually check: if `pyyaml` or `ruamel.yaml` is already a project dependency, use it. Otherwise parse YAML frontmatter manually with regex.
